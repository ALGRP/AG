# 05 — Infrastructure and n8n Audit

Audit: AGOS_WEB_RELEASE_PROGRAM_FABLE_5_1_MASTER_AUDIT_R1 · Date: 2026-09-01 · Mode: STRICT_READ_ONLY.
Scope: shared Caddy / Docker / MariaDB / PostgreSQL / WordPress staging / n8n on the Hetzner-class
host, the n8n instance that is already live, and the host-provider accounts that keep them running.

## 1. Verdict

**N8N_FOUNDATION_READY = NO.** The IaC in `ALGRP/agos-infrastructure` is a sound skeleton (isolated
Compose projects, internal-only databases, Caddy with security headers, secrets outside git), but the
n8n that is **actually running in production is not the one described by that repo in any verifiable
way**, its workflows are not under version control, the image tag is unpinned against a High-severity
advisory, there is no backup or restore evidence, the documented basic-auth guard is a no-op on n8n 1.x,
and the hosting/CDN/billing layer around it received suspension notices in August 2026.
